# DeleteForeverReborn

Adds a **Permanently Delete** button to the delete sheet in Photos and Camera, skipping Recently Deleted.

Rebuild of DeleteForeverXS by [P2KDev](https://github.com/p2kdev). Supports iOS 15–26, rootless and roothide.

## Build

```bash
make package FINALPACKAGE=1 THEOS_PACKAGE_SCHEME=roothide
make package FINALPACKAGE=1 THEOS_PACKAGE_SCHEME=rootless
```
